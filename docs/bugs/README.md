## 一、怎么用

1. **动工前**：查本文件的总表 → 找到相关条目 → 进对应领域文档看「现象 / 根因 / 修复 / 验证」。
2. **修完新缺陷**：先在本文件加一行 + 在领域文档加一条完整记录，再写代码 —— 防止同类问题重复踩。
3. **要细节**：每条都标了「来源」（**版本 / 专项**）。过程数据与测量方法在 [`../技术支持/技术数据-大库压测与性能.md`](../技术支持/技术数据-大库压测与性能.md)，版本级技术细节在仓库根 `CHANGELOG.md`。

**编号规则**：`领域代号-序号`，序号按发现时间递增，**一经分配不再变更**。

| 代号 | 领域 | 文档 |
|---|---|---|
| `AR` | 架构 / Electron / Vue 运行时 / 测试调试 | [BUG-架构与渲染.md](BUG-架构与渲染.md) |
| `DF` | 数据 / 文件 / 字段口径 / 扫描落盘 | [BUG-数据与文件.md](BUG-数据与文件.md) |
| `AI` | AI 打标 / 本地向量 / 标签体系 | [BUG-AI打标与标签.md](BUG-AI打标与标签.md) |
| `PK` | 性能 / 大库 / 内存 / 索引 | [BUG-性能与大库.md](BUG-性能与大库.md) |
| `RL` | 发布 / 打包 / 更新 / OTA | [BUG-发布更新与打包.md](BUG-发布更新与打包.md) |
| `CT` | 测卡工作区（对话测试） | [BUG-测卡工作区.md](BUG-测卡工作区.md) |

**等级**：🔴 严重（崩溃/数据丢失/功能不可用） ｜ 🟡 中（功能异常但有绕法） ｜ 🟢 轻（体验/精度/日志）

## 五、已知非缺陷（勿重复排查）

> 这些现象**看起来像 BUG，实际是设计如此或环境限制**。历史上被重复排查过，列出来省时间。

| 现象 | 结论 |
|---|---|
| 导入**同名卡**被跳过、没覆盖 | **设计如此**：`importCardFiles` 明确「同名跳过，绝不覆盖」 |
| 快捷筛选/列表里某些计数为 0 | 先看 [DF-11](BUG-数据与文件.md)（轻量字段口径），再看是否只是索引/筛选未就绪 |
| `KeystorePlugin` 被注册两次 | Capacitor **内部行为**，无功能影响（移动版） |
| 模拟器/真机测试卡住、`adb` 一直 offline | SDK **路径含中文**导致 emulator 内部乱码挂死 → 用 ASCII 路径 junction 规避（移动版） |
| `BestClock: Missing network time fix` | 模拟器无网络时间同步，**与 App 无关** |
| ECharts 关系图谱节点点击无法自动化 | zrender 分层渲染、位置不可靠 → **只能手动验证** |
| 长按动作菜单在 CDP/adb 下触发不了 | Android WebView 合成器独立处理手势 → **只能真机手动验证** |
| `vite build` 后 `web/` 里还有旧文件 | `build:web` 才清 `web/`；只跑 `vite build` 不清理 |
| 重复点击已激活的 Tab 没反应（自动化） | 侧栏只在聊天 Tab 挂载时创建 → 测试须「先切走再切回」（见 [CT-12](BUG-测卡工作区.md)） |
| 页面里的外链图片不显示 | 应用 CSP 拦截 http(s) 图片（防追踪像素），**设计如此** |

> `CHANGELOG.md` 与 `docs/规格与计划/**` 是**活文档**，缺陷条目在它们里也会同步出现（分工：那里写「做了什么」，这里写「坏在哪、怎么修」）。
