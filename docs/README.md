## 六、维护约定

> 完整规则见 [`文档整理规则.md`](文档整理规则.md)（唯一归属 / 活数字口径 / 版本号联动清单 / 整理 SOP）；本节只是速记。

1. **新缺陷**：先在 `bugs/README.md` 加一行，再在对应领域文档加「现象/根因/修复/验证」完整条目，**然后**才写修复代码。
2. **新代码片段 / 新实测数据**：进 `技术支持/`；实测数据要写清**测量方法与口径**（同一份代码首屏可在 16~31s 间波动，必须同会话交替 A/B）。
3. **发版**：按 `发布/规范与流程/一条龙-发布流程.md` 走，注意内部 / 对外文档分工（`发布/规范与流程/内部信息.md`、`发布/规范与流程/用户可看信息.md`）。
4. **旧文档**：内容一旦并入新体系，旧文件**直接删除**（不保留归档目录）；新体系里不再保留旧文件路径引用。
