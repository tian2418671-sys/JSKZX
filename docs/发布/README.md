## 三、速记

- 发版步骤：按 [`规范与流程/一条龙-发布流程.md`](规范与流程/一条龙-发布流程.md) 走。
- Release 正文**必须**由 `node scripts/extract-release-notes.mjs vX.Y.Z` 从 `RELEASE_NOTES.md` 抽取，**不许手抄**。
- 对外 / 内部判定与文案口径：见 `规范与流程/内部信息.md` 与 `规范与流程/用户可看信息.md`。
