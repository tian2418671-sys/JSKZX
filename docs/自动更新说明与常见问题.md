# 自动更新说明与常见问题

> 本文面向普通用户，解答更新相关的常见问题：
> 1. 为什么更新时快时慢？
> 2. 为什么自动更新后会出现「重启失败」？
> 3. 各种更新「疑难杂症」怎么排查？
>
> 文中不含任何代码，请放心阅读。

---

## 一、更新是怎么工作的（30 秒看懂）

本软件的自动更新流程大致是：

```
检测新版本 → 你点「下载更新」→ 下载完整安装包（约 106 MB）→ 静默安装 → 自动重启
```

有两个关键点需要先了解：

1. **下载的是「完整安装包」，不是小补丁。** 每次更新都要下载一个约 106 MB 的文件，所以网络好坏会直接影响下载时长。
2. **安装是「静默」的。** 安装过程不弹安装向导界面，装完自动帮你重启软件。这个过程如果被系统或安全软件打断，就会出现「重启失败」。
3. **更新只替换程序文件，不碰你的数据。** 你导入的角色卡、世界书、预设、设置都存在另一个专属数据目录里（详见第六节），更新/重装都不会动它。

## 二、为什么更新「时快时慢」？

这是**网络原因**，不是软件本身的问题。具体来说：

### 1. 更新服务器在境外

更新文件存放在 GitHub（国际代码托管平台）的服务器上，物理位置在海外。国内网络访问它时，数据要经过国际线路，速度天然不稳定。

### 2. 每次要下载约 106 MB 的完整包

因为不是「增量更新」（只下载变化的小部分），而是每次拉完整安装包，所以：
- 网络顺畅时：几分钟内下载完，感觉「快」；
- 网络拥堵时：同一个文件可能卡很久，感觉「慢」。

**文件大小没变，变的是你当时的网速。**

### 3. 影响速度的几个常见因素

| 因素 | 说明 |
|------|------|
| **时段** | 晚高峰（20:00–23:00）国际线路拥堵，明显变慢；凌晨/白天通常更快 |
| **运营商/网络环境** | 不同宽带、公司网络、校园网的出口质量差异很大 |
| **是否开了代理/加速器** | 开了代理走境外线路通常更快；没开则取决于运营商直连质量 |
| **服务器负载** | GitHub 的下载节点繁忙时也会限速 |
| **下载中断重试** | 网络抖动会导致下载中断后从头重来，看起来更慢 |

### 4. 结论

> **「时快时慢」是国际网络波动的正常现象，与软件版本无关。** 遇到慢的时候，换个时间段重试，或开启代理/加速器，通常就能解决。

## 三、为什么自动更新后会「重启失败」？

「重启失败」通常不是软件崩溃，而是**更新安装这一步被打断了**。常见原因如下：

### 原因 1：安全软件拦截（最常见）

因为本软件**没有购买数字签名证书**，安装包是未签名的，且使用了 Electron 框架（很多安全软件会误判这类程序）。

360、火绒、腾讯管家、Windows Defender 等安全软件可能在「静默安装」这一无界面环节：
- 拦截安装包；
- 隔离安装程序；
- 阻止安装完成后自动重启。

**表现：** 下载进度到 100% 后，软件关掉了，却没有重新打开，或弹出报错。

### 原因 2：旧程序没有完全退出（文件被占用）

更新安装需要「替换正在运行的程序文件」。如果旧进程没有彻底退出（例如还有后台进程、托盘图标残留），Windows 会因为「文件被占用」而无法完成替换，导致安装中断。

**表现：** 更新后手动打开软件，发现版本号还是旧的。

### 原因 3：安装包下载不完整 / 损坏

如果下载过程中网络中断，下载到本地的安装包可能不完整。静默安装校验失败时就会中断。

**表现：** 下载完成但安装/重启时报错。

### 原因 4：安装位置权限不足

正常安装位置（用户目录）不需要管理员权限，可以静默更新。但如果你当初把软件装到了需要管理员权限的位置（如 `C:\Program Files`），静默安装就可能因为权限不足而失败。

### 原因 5：磁盘空间不足

完整安装包约 106 MB，安装后还需要额外空间。如果系统盘剩余空间过小，安装会失败。

### 原因 6：安全软件「回滚」了安装

部分安全软件（尤其 360）检测到未签名程序写入时，会自动**静默回滚**安装操作，看起来像是「更新失败/重启失败」，但安全软件界面可能只显示一条不起眼的记录。

## 四、遇到问题怎么办（按顺序尝试）

### ✅ 方案 A：安全软件临时放行（针对原因 1、6）

1. 更新前，暂时退出或对软件设置「信任/白名单」；
2. 如果 360/火绒等弹窗拦截，选择「允许运行」或「信任」；
3. 更新完成后再恢复安全软件即可。

### ✅ 方案 B：先完全退出，再手动更新（针对原因 2、3）

如果自动更新反复失败，最稳妥的办法是**手动更新**：

1. 完全退出软件（确认任务栏、托盘区都没有残留图标）；
2. 打开官方下载页：
   - 安装版（推荐）：https://github.com/tian2418671-sys/JSKZX/releases/latest
3. 下载最新的 `sillytavern-card-manager-x.x.x.exe`；
4. 双击重新安装（覆盖安装即可，数据不会丢失）；
5. 如果你用的是绿色版，下载 `zip` 解压后直接覆盖旧文件即可。

### ✅ 方案 C：以管理员身份运行（针对原因 4）

如果软件装在需要权限的目录，可以右键软件 → 「以管理员身份运行」后再触发更新。

### ✅ 方案 D：检查磁盘空间（针对原因 5）

确认系统盘有至少 500 MB 以上的剩余空间，再重试更新。

### ✅ 方案 E：实在不行就「卸载重装」

1. 先备份数据（见第六节）；
2. 卸载旧版本；
3. 重新下载最新版安装。

> 卸载重装 **不会** 删除你的角色卡、世界书、设置等数据，它们存在独立的数据目录里。

## 五、疑难杂症速查（大合集）

### 5.1 更新相关

| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| 下载特别慢 / 卡住不动 | 国际网络波动、晚高峰 | 换时间段重试，或开代理/加速器 |
| 下载进度到 100% 但没重启 | 安全软件拦截静默安装 | 方案 A：临时放行安全软件 |
| 更新后版本号还是旧的 | 旧进程未退出、文件被占用 | 方案 B：完全退出后手动重装 |
| 下载进度卡在中间不动 | 网络中断，正在重试 | 等待或取消后重新下载 |
| 下载到一半报「网络错误」 | 网络抖动、代理失效 | 重试；确认代理/加速器状态正常 |
| 点「下载更新」没反应 | 安全软件拦截了下载请求 | 方案 A；或手动下载安装 |
| 检查更新一直转圈 | GitHub 连接不稳定 | 稍后重试；开代理/加速器 |
| 提示「已是最新版本」但感觉有新功能 | 新版刚发布，检测有延迟 | 稍后再试；或手动打开下载页确认 |
| 更新后弹「重装向导」界面 | 旧版本的问题 | 升级到最新版即可（新版为静默升级） |
| 更新后软件打不开 / 白屏 | 安装包损坏或被杀软回滚 | 方案 B 手动重装 |
| 更新后快捷方式丢失 / 指向旧版 | 安装中断、覆盖不完整 | 重新运行最新安装包修复 |
| 更新后设置被重置成默认 | 数据目录被安全软件隔离 | 恢复白名单后重启软件；见第六节备份 |
| 绿色版提示「不支持自动更新」 | 绿色版没有更新机制 | 用安装版；或手动下载 zip 覆盖 |
| 每次打开都提示更新，更新完还提示 | 安装未生效（文件被占用） | 方案 B：完全退出后重装 |

### 5.2 安装相关

| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| 安装包被杀软报毒/隔离 | 未签名 + Electron 框架特征 | 加白名单/信任；从官方链接下载 |
| 双击安装包没反应 | 被杀软拦截，或系统未响应 | 查看安全软件隔离区；右键「以管理员身份运行」 |
| 安装时提示「另一个程序正在使用此文件」 | 旧版本还在运行 | 完全退出软件（含托盘）后重试 |
| 安装到一半失败/自动回滚 | 权限不足、磁盘不足、被杀软回滚 | 方案 C / D / A |
| 提示「需要管理员权限」 | 安装位置需要提权 | 右键「以管理员身份运行」 |
| 覆盖安装后旧快捷方式失效 | 安装目录变更 | 重新安装后从开始菜单启动 |

### 5.3 启动 / 运行相关

| 现象 | 可能原因 | 解决办法 |
|------|----------|----------|
| 双击图标没反应 | 被杀软拦截 | 查看安全软件记录，加信任 |
| 启动白屏 / 黑屏 | 显卡驱动兼容问题 | 升级显卡驱动；以兼容模式运行 |
| 启动很慢（千卡库） | 卡片库很大，首次索引 | 等待完成；旧版本请升级 |
| 大卡片切换卡顿 | 旧版本性能问题 | 升级到最新版 |
| 世界书改完保存丢失 | 旧版本 bug | 升级到 v1.8.4+ |
| 导入 JSON 卡后角色栏消失 | 内嵌世界书格式问题 | 升级到 v1.8.4+ |
| 系统提示「应用程序无法正常启动」 | 安装损坏 / 被杀软破坏 | 重新安装最新版 |
| 之前能用，某天突然打不开 | 安全软件更新后误杀 | 恢复文件到白名单；必要时重装 |

### 5.4 数据安全（消除顾虑）

| 疑问 | 回答 |
|------|------|
| 更新/重装会丢数据吗？ | **不会。** 角色卡、世界书、预设、设置都存在独立的数据目录，更新只替换程序文件 |
| 数据存在哪里？ | 系统用户目录下的应用数据文件夹（`C:\Users\你的用户名\AppData\Roaming\SillyTavern 角色卡管理器`） |
| 卸载会删数据吗？ | 卸载程序默认会清理部分数据，**建议卸载前先备份**（见下方） |
| 如何备份？ | 复制上述 `AppData\Roaming\SillyTavern 角色卡管理器` 文件夹到别处即可；恢复时复制回去 |
| 备份文件是加密的吗？ | 数据以文件形式存放在本地，**不上传任何云端**，纯本地工具 |

## 六、一句话总结

- **更新快慢** → 取决于你访问境外服务器的网速，**不是 bug**。
- **重启失败** → 多为**安全软件拦截**或**旧进程没退干净**，手动重新安装即可解决。
- **疑难杂症** → 九成以上都能用「**安全软件放行 + 完全退出 + 手动重装**」三板斧解决。
- **数据安全** → 更新/重装都不影响你的角色卡、世界书和设置，可放心操作；重要数据建议定期备份。

> 本软件是纯本地工具，不上传任何用户数据。更新不会影响你已导入的角色卡、世界书等任何本地数据，请放心更新。
