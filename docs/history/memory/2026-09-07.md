# 2026-09-07 导入标签清洗开关失效（新卡仍被贴标签）修复记录

> 今日主题：用户反馈「设置菜单 · 导入时忽略卡片自带标签」开关打开后，导入新角色卡依旧有标签被导入。
> 定位到开关契约与实际实现的错位并修复，含单元回归测试 + Electron CDP 热测试验证。

---

## 一、问题现象

开启「导入时忽略卡片自带标签」（`sanitizeImportedTags`）后，经文件菜单导入**全新**角色卡，
卡片上仍出现标签（如「Fantasy (奇幻)」「Romance (恋爱)」等），体感开关失效。

## 二、根因（两层）

### 直接原因：自动打标规则不受开关约束
- v2.1 引入的 44 条系统预设规则（`cardLoader.js` `defaultAutoTagRules`）**默认全部生效、无整体关闭入口**，
  导入时对每张新卡跑正则（`useCardCrud.js` `processAutoTagsAndCategory` 规则循环），
  命中即写入 `customTags` 并物理写回 PNG。
- 开关只清空卡片自带的原生 `data.tags`（原兜底分支内的 v2.1.4 物理清除），
  **从不拦截规则标签** → 开关开启后新卡照样被贴上规则标签。
- 开关契约（App.vue「导入数据清洗开关」注释）：「开启后仅保留自动分类结果」——即开关开启时
  导入只保留**分类**，不应附加任何标签（既不含卡片自带、也不含规则生成）。

### 次生缺陷：4 条提前 return 绕过物理清洗
`processAutoTagsAndCategory` 的原生 tags 清空只在自动规则兜底分支执行，
以下分支提前 return 时外来原生标签残留内存与磁盘文件（关闭开关后复活、混入全局标签池）：
- `subFolder`（物理子文件夹卡）
- 覆盖层命中（app_config `cardOverlays`）
- `importedConfig`（库配置导入的历史配置，还会把历史外来标签复活进新卡 customTags）
- `localCategoryMap`（localStorage 手动分类，按**卡片名**永久累积命中）

## 三、修复（`js/composables/useCardCrud.js` `processAutoTagsAndCategory`）

1. **物理清洗上移到函数入口**：开关开启时先于所有分支清空原生 `data.tags`
   （兼容数组与 V1 字符串形态），堵住 4 条提前 return 的绕过；用户标签仍由覆盖层随后恢复。
2. **规则循环改为只定分类**：开关开启时规则命中只更新 `assignedCategory`（自动分类保留），
   不再 push 进 `generatedTags`/`customTags`；开关关闭时逐条件保持原行为，无回退。
3. 删除兜底分支内重复的清空代码（已上移）。

## 四、验证

### 单元回归（`npm test` 104 用例全绿）
- 新增 `test/sanitizeImport.test.mjs`（7 用例，直接调生产函数）：
  开关开+全新卡（不贴规则标签、分类保留、原生清空）/ localCategoryMap / 覆盖层 /
  importedConfig / 子文件夹 / V1 字符串 tags / 开关关闭对照。
- 更新 `test/cardCrud.test.mjs` 1 条旧断言（原断言「开关开启时规则标签照常生成」→
  新契约「不贴标签、只定分类」）。

### Electron CDP 热测试（`scripts/sanitize-live.mjs`，真实库环境）
- 开关开启导入带外来标签的测试卡：customTags 空、nativeTags 空、全局标签池无污染，
  自动分类照常（Fantasy）→ 修复生效。
- 对照：开关关闭导入同样卡片：原生+规则标签全部带入、池被污染 → 原有行为无回退。
- 测试后已清理：测试卡从库内存/磁盘移除、导入时间记录清除、开关恢复原值、进程停止。

## 五、附带事项

1. **node_modules 缺 jquery**（package.json 已声明但未安装）→ 开发模式 `hostStub.js`
   `jquery/dist/jquery.min.js?raw` 解析失败、应用无法加载。已 `npm install jquery` 补装
   （清单无改动）。后续 CI/打包环境同样需完整安装。
2. **开关开启时"扫描也清洗"**：修复后启动/刷新扫描会对命中路径的库内旧卡做物理清洗
   （开关注释「导入/扫描卡片时」的既有契约范围）；覆盖层中的用户标签不受影响。
   若未来要求收紧为「仅新导入卡生效」，需另行调整清洗时机判定。
