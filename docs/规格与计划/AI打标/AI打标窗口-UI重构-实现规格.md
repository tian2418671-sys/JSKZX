## 〇、为什么改（问题诊断）

用户反馈「AI 标签窗口有点混乱，UI 布局不合理」。取证后确认 5 个具体问题：

| # | 现象 | 根因 |
| --- | --- | --- |
| 1 | 窗口窄、内容挤 | 单列长滚动，`max-w-2xl`（672px）装不下 7 个功能块 |
| 2 | 找不到关键控件 | 执行进度条在被折叠的顶部区域，滚动后看不见 |
| 3 | 提示词相关控件混在「AI 打标规则设置」里 | 从属关系不清，语义上不属于规则设置 |
| 4 | 「📝 管理规则表」入口出现两次 | 历史叠加，两处都在渲染 |
| 5 | 找不到自己想要的页 | 无分区导航，只能靠滚动定位 |

**参照范式**（项目内既有，保持一致）：

- `TagCategoryModal` —— 左导航（`w-80`）+ 右内容
- `AutoGroupModal` —— `max-w-5xl` 宽窗
- 外部参考：SillyTavern `vectors/settings.html` —— `inline-drawer` 折叠 + `<hr>` / `<h4>` 分组

## 一、目标布局（方案 B：左导航分区）

```text
┌───────────────────────────────────────────────────────────┐
│  🤖 AI 打标                                        [×]    │
│  ▓▓▓▓▓▓▓▓░░░░░░░ 进度条（置顶常驻，不随分区切换消失）      │
├──────────────┬────────────────────────────────────────────┤
│ 本次打标      │                                            │
│  ⚙️ 执行管线  │                                            │
│  🏷️ 候选标签池│           当前分区内容                     │
│  📝 AI 提取设置│          （v-show 切换）                  │
│ 引擎设置      │                                            │
│  🧠 本地向量  │                                            │
│  ⚡ API 引擎  │                                            │
│ 提示词        │                                            │
│  📝 系统提示词库│                                          │
│  ⚠️ 强制破限  │                                            │
├──────────────┴────────────────────────────────────────────┤
│                      底部操作栏（常驻）                    │
└───────────────────────────────────────────────────────────┘
```

| 项 | 值 |
| --- | --- |
| 窗口宽度 | `max-w-2xl`（672px）→ **`max-w-5xl`（1024px）** |
| 最大高度 | `max-h-[92vh]` |
| 左导航 | `w-52`，分组标题 + 条目按钮；选中态 `bg-indigo-600 text-white font-bold` |
| 分区切换 | `v-show="activeSection === '<key>'"`（保留 DOM，避免状态丢失） |
| 分区键 | `pipeline` / `candidates` / `extract` / `vector` / `api` / `prompts` / `jailbreak` |
| 导航数据 | `navGroups()` 方法返回 `[{ title, items: [{ key, icon, label, badge }] }]` |
| 徽标 | 动态：候选标签池 = `aiCandidateTags.length`、本地向量 = `开`、系统提示词库 = `systemPromptPresets.length`、强制破限 = `开` |

## 二、三组七分区

| 组 | 分区（key） | 内容 |
| --- | --- | --- |
| **本次打标** | `pipeline` ⚙️ 执行管线 | 打标规则表入口（📝 管理规则表，**去重后唯一**）、执行 / 停止、进度与结果摘要 |
| | `candidates` 🏷️ 候选标签池 | 候选标签列表、折叠分组、批量勾选 |
| | `extract` 📝 AI 提取设置 | 标签提取正则 / 提示词片段等提取链路配置 |
| **引擎设置** | `vector` 🧠 本地向量 | 本地向量模型开关与状态 |
| | `api` ⚡ API 引擎 | 供应商 / 模型 / 温度等 API 参数 |
| **提示词** | `prompts` 📝 系统提示词库 | 系统提示词预设的增删改与选择 |
| | `jailbreak` ⚠️ 强制破限 | **从「AI 打标规则设置」块中抽出**，独立成区 |

## 三、改动要点

1. 外框：`w-full max-w-2xl` → `w-full max-w-5xl`；内容区改 `flex`（左导航 + 右内容）。
2. 进度条：从折叠区移到**标题栏正下方常驻**，切分区不消失。
3. 分区包裹：原有 7 个功能块逐个加 `v-show="activeSection === '<key>'"`，块内结构不动（降低回归面）。
4. 强制破限：从「AI 打标规则设置」剥离，独立成 `jailbreak` 区。
5. 去重：删除重复的「📝 管理规则表」入口，仅保留 `pipeline` 区一处。
6. 新增 `data.activeSection = 'pipeline'` 与 `methods.navGroups()`。

**实现中修掉的自伤缺陷**（记录以防再犯）：

- 4 处 `</div>` 缺失 → Vue 编译报 "missing end tag"（结构性改动必须逐层数闭合）；
- 2 处同时写了 `block` 与 `flex` 的冗余类；
- 导航 key 手误写成 `aiextract`，与模板 `extract` 不匹配 → 切到该区会空白。

## 四、验证证据

| 关卡 | 结果 |
| --- | --- |
| `npm test` | **471 / 471 通过**（41 个测试文件） |
| `npm run build:web` | 干净（无警告） |
| 生产构建真实启动冒烟 | 无 `[Vue 错误]`、无 `crash.log` |
| CDP 探针 `scripts/probes/_probe-aitag-nav.mjs` | **12 / 12 通过** |
| 截图人工核对 | 三组七分区布局与原型一致 |

**探针断言清单**（`_probe-aitag-nav.mjs`）：

1. 左导航渲染出 **3 个分组标题**；
2. 导航条目共 **7 个**，key 与 `navGroups()` 一致；
3. 逐个点击切区后，各自**特征控件可见**（如 `jailbreak` 区可见破限开关、`vector` 区可见向量开关）；
4. 「📝 管理规则表」**可见实例恰好 1 个**（去重生效）；
5. 全程无渲染错误 / 控制台报错。
