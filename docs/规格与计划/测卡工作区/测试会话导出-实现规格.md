# 测试会话导出 — 实现规格

> 本文件是什么：**下一版本待做功能**「测卡会话导出」的实现规格（Markdown / HTML / 纯文本三格式 + 通用保存 IPC）。
> 与相邻文档的分工：测卡引擎结构见 [`桌面版测卡工作区-实现规格.md`](桌面版测卡工作区-实现规格.md)；总排期见 [`../计划与记录/下次更新计划-五功能升级.md`](../计划与记录/下次更新计划-五功能升级.md)。
> 最后更新：2026-10-03 ｜ 状态：✅ **已落地（2026-10-03）**（落地记录见文末）

---

## 一、目标

把「聊天测试」里跑出来的会话导出为本地文件，用于留档 / 分享 / 复盘：

- **Markdown（默认）**：头部元信息 + 按消息分节，适合笔记工具；
- **HTML 单文件**：样式内联、双击可看（含 HTML 段渲染结果），适合分享；
- **纯文本**：最简，适合粘贴。

顺带落地**共享基础设施**：通用「保存文本文件」IPC（本项目此前只有专用导出通道，无通用文本保存）——「一键质检流水线」的报告导出也复用它。

## 二、现状

- 会话数据：`chat_store.json`（`loadChatStore` / `saveChatStore` IPC，原子写）；会话结构以 `js/composables/chat/useChatSessions.js` 与 `chatStorage.js` 实际字段为准（消息：role / content / 分段 / 时间戳 / swipe 分支）；
- 渲染：`useChatRender` + `ChatPanelSeg.vue`（含 HTML 段 iframe/沙箱、状态栏、变量）；
- **无任何导出/保存文本能力**（`preload.js` 现有导出均为卡/书/预设专用批量包）。

## 三、设计

### 3.1 共享底座：`file:saveTextFile`（主进程 + preload 新增）

| 项 | 内容 |
| --- | --- |
| IPC | `file:saveTextFile`（`{ defaultName, content, filters?, encoding? }` → `{ ok, canceled, path }`），主进程 `dialog.showSaveDialog`（`defaultPath` = 下载目录或桌面）+ `fs.writeFile`（默认 UTF-8）；写失败返回明确错误 |
| 安全 | 只写用户**在对话框里显式选择**的路径（不接收任意路径参数，防注入） |
| 复用方 | 本功能；质检流水线报告导出；未来其他「导出文本」场景 |

### 3.2 导出纯函数（新 `js/utils/chatExport.js`，可单测）

```text
buildSessionMarkdown(session, opts) → string
buildSessionHtml(session, opts)     → string
buildSessionPlainText(session, opts) → string
```

- **元信息头**（三格式一致）：卡名 / 会话标题 / 导出时间 / 模型 / 预设名（有则记）；
- **Markdown**：每条消息 `### 角色名 · 时间`，正文原样（转义 `#` 等仅在需要时）；HTML 段附「⛩️ HTML 渲染内容（请用 HTML 版查看完整效果）」+ 可选的纯文本摘要；状态栏/变量快照以 `yaml` 代码块附在末尾（可选开关，默认附）；
- **HTML**：单文件、`<meta charset>`、**内联关键样式**（消息块 / 角色名 / 时间 / HTML 段容器——取面板等效浅色主题，不引外部 CSS）；HTML 段取**已渲染 DOM 的 `outerHTML`** 包进 `<section class="seg-html">`（保留原样、**不执行脚本**，仅静态展示）；
- **纯文本**：`[角色名] 正文` 顺序拼接；
- 文件名：`会话_<卡名>_<yyyyMMdd-HHmm>.md|.html|.txt`（清洗 Windows 非法字符，截断 80 字符）。

### 3.3 UI 与落点

| 文件 | 改动 |
| --- | --- |
| `js/components/ChatTestSidebar.vue`（或测卡面板工具条） | 新增「⬇️ 导出会话」下拉（Markdown / HTML / 纯文本）；空会话禁用 |
| `js/composables/chat/useChatSessions.js` | 新增 `exportCurrentSession(format)`：取当前会话 → 调纯函数 → `file:saveTextFile` |
| `main.js` + `preload.js` | `file:saveTextFile` |
| `test/chatExport.test.mjs`（新） | 纯函数单测 |

### 3.4 边界与口径

- 导出 **当前激活的 swipe 分支**（与界面所见一致）；
- HTML 段内容携带用户的酒馆脚本产物——**原样保留**（这是内容而非可执行环境；导出文件不会自动执行任何脚本）；
- 超长会话（>10MB 文本）提示确认后再导出；
- 导出**不写**任何应用配置文件（纯下载）。

## 四、验收口径

1. 单测：转义、空会话（禁用逻辑在 UI 层）、HTML 段拼接、文件名清洗、swipe 分支选取；
2. **副本库**演练：含 HTML 段 / 状态栏 / 多轮 / swipe 的会话三种格式各导出一次；
3. HTML 文件**断网双击**打开：字符集、样式、消息顺序正常；
4. Markdown 粘进常见笔记工具结构不散（标题层级、代码块闭合）。

## 五、风险与注意事项

- 面板样式会演进：导出内联样式**明确固定为「导出模板」**（不追求与面板 100% 像素一致，避免每改 UI 都动导出）；
- HTML 段的 `outerHTML` 可能含 `<script>`——导出时**不剥离但也不转义**（本地文件语义），预览/分享提示由用户自担；
- `file:saveTextFile` 是通用底座：**不接任意路径**，只走系统对话框，避免成为写文件后门。
