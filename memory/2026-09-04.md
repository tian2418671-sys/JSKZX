## 三、关键 BUG：自定义分类 key 碰撞（★ 相似 BUG 全查）
- 根因：`addCustomTagCategory` key = `Date.now().toString(36)`，同一毫秒连续建多类（AI 一次应用连建）碰撞
  → 不同名分类共用 key、标签归属错乱、UI 出现重复条目同显一批标签。
- 修复：key 追加随机段；`normalizeTagName`（零宽/全角/NBSP 折叠）判重；add 幂等返回已有 key；
  `mergeDuplicateTagCategories` 合并同名变体；`ensureUniqueCustomCategoryKeys` 修复历史同 key。
- 相似 BUG 扫描：全仓 `toString(36)`/时间戳 key 生成均带随机段，无其它裸时间戳 key（safe）。
- 真实数据已 CDP 修复 + 磁盘核验（分类 key 唯一）。
